# Demo video

`twinprice-demo.mp4` (1920x1080, about 20 seconds) is recorded by
`scripts/build-demo-video.mjs` against the fictional capture shop. Every
conversion in it was performed by the real extension, using the round
fixture rates rather than live market rates. The file is not committed.
Rebuild it with `npm run build:video` (ffmpeg must be on PATH).
