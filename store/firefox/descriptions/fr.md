**Voyez ce que coûte un prix étranger dans votre propre devise, juste à côté de l'original.**

Ouvrez une boutique qui affiche une autre devise : Twinprice trouve les prix, propose de les convertir et vous montre le taux avant que vous acceptiez. Chaque montant converti s'affiche à côté de l'original, pour que vous voyiez toujours ce que la boutique facture vraiment.

Fonctionne dans Firefox sous Windows, macOS et Linux, ainsi que dans **Firefox pour Android**.

**Ce que vous pouvez convertir**

- **Tous les prix d'une page**, en un clic
- **Un prix que vous sélectionnez**, avec le bouton qui apparaît à côté ou, sur ordinateur, le menu contextuel
- **N'importe quel montant** saisi dans la fenêtre de la barre d'outils

**Devises**

- Plus de 160 devises de destination, avec recherche par code ou par nom
- 50 devises détectées automatiquement sur la page
- Formats corrects, comme le yen sans décimales et le dinar avec trois

**Pensé pour de vraies boutiques**

- Gère les affichages de prix compliqués, par exemple sur Allegro, Digitec, Trendyol et tap.az
- Repère les prix que les boutiques modernes chargent plus tard
- Convertit automatiquement sur les boutiques que vous choisissez, et seulement là
- Annuler remet la page exactement dans son état d'origine
- Raccourci clavier sur ordinateur : Ctrl+Maj+Y (Commande+Maj+Y sur Mac)
- Interface en vingt-deux langues : English, Čeština, Deutsch, Español (España), Español (Latinoamérica), Français, Bahasa Indonesia, Italiano, Bahasa Melayu, Nederlands, Polski, Português (Brasil), Română, ไทย, Türkçe, Українська, O‘zbekcha, Tiếng Việt, 日本語, 한국어, 简体中文 et 繁體中文

**Pourquoi Firefox demande l'accès à tous les sites et mentionne le contenu des sites web**

Un prix peut se trouver sur n'importe quelle boutique, donc Twinprice doit lire les pages que vous ouvrez pour le repérer. Il ne les lit **que sur votre appareil**. Le contenu des pages, les prix et les sites visités ne quittent jamais votre navigateur. La seule chose envoyée est un code de devise à trois lettres, comme EUR, pour obtenir le taux de référence du jour. Seule exception : **Signaler ce site**. Si une page ne se convertit pas et que vous appuyez dessus, seul le nom du site, par exemple shop.example, est envoyé à twinprice.com pour qu'il puisse être corrigé. Firefox vous demande l'autorisation la première fois. Pas de publicité, pas d'analyse, pas de pistage.

**À propos des taux**

Les taux de référence viennent de [Frankfurter](https://frankfurter.dev/), qui publie les taux de la Banque centrale européenne chaque jour ouvré. Ils servent à comparer des prix. Ce ne sont pas les taux qu'appliquera votre banque ou votre carte, et ils n'incluent pas les frais.

**Limites**

Les prix dans des images et dans certains cadres intégrés ne peuvent pas être convertis. Sur des pages inhabituelles, il faudra parfois choisir vous-même la devise d'origine.
