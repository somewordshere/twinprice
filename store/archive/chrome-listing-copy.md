# Chrome Web Store Listing Copy

## Listing name

Currency Converter Pro

## Short description

Detect webpage prices privately and offer fast one-click conversion with searchable currencies and cached exchange rates.

## Full description

Currency Converter Pro makes prices on international websites easier to understand without sending webpage content away from your browser.

When an ordinary webpage opens, Currency Converter Pro scans locally for supported prices and shows a conversion prompt only after a likely price is found. Convert recognized prices across the page, highlight one supported price, or type an amount directly into the popup. Keep AUTO selected for conservative webpage detection, or search the exchange-rate provider's active currency catalog by code or name when you want to choose the source currency manually.

Key features:

- Detect supported prices locally as ordinary webpages open
- Show the on-page conversion prompt only after a supported price is found
- Convert a highlighted price or recognized prices across a webpage
- Convert typed amounts directly in the popup
- Search source and target currencies by currency code or name
- Follow prices added later by modern dynamic shopping pages
- Keep the original price beside the conversion or show only the converted value
- Remember only websites you explicitly approve for automatic conversion
- Keep recently used currencies close at hand
- Convert page prices with Ctrl+Shift+Y, or Command+Shift+Y on macOS
- Use recent cached rates immediately while fresh rates load in the background, never using a cache more than seven days old
- No advertisements or analytics

How to use:

1. Open an ordinary webpage containing a supported price.
2. Select Convert prices when the on-page prompt appears.
3. Open Currency Converter Pro from the Chrome toolbar to change the source or target currency.
4. Open Convert custom amount to enter a value, or use Convert page prices to run the page conversion directly.
5. Open Page options to change the price display or enable automatic conversion for the current website.

Privacy:

Price detection starts automatically on ordinary HTTP and HTTPS webpages and happens locally in Chrome. Page contents, highlighted text, price values, visited URLs, and browsing history are not sent to the developer or the exchange-rate provider. Only ISO currency codes are sent to Frankfurter to retrieve reference rates.

The extension stores preferences, recent currency choices, cached exchange rates, and only the website origins you explicitly approve for automatic conversion. Some settings may sync through Chrome according to your browser settings. Currency Converter Pro does not include advertising or analytics trackers.

Exchange rates are intended for convenient price comparison and may differ from rates used by banks, card providers, payment services, or currency exchanges. Fees and provider margins are not included.

## Store-asset wording

Use **“Highlight a supported price”** instead of “Highlight any price on any webpage.”

Use **“Works on modern shopping pages”** instead of “Works everywhere.”

Use **“No browsing data sent”** instead of “No data stored,” because settings,
remembered origins, recent currencies, and cached rates are intentionally stored by the
extension.

Do not claim support for browser-internal pages, closed shadow roots, images, or
inaccessible cross-origin frames.
