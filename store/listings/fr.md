# French listing (fr)

Chrome: Developer Dashboard > Store listing > language "French" > Description.
Firefox: Developer Hub > Edit Product Page > language "Français".

---

Voyez ce que coûte un prix étranger dans votre propre devise, là où il s'affiche sur la page, à côté de l'original.

Ouvrez une boutique qui affiche une autre devise : Twinprice trouve les prix, propose de les convertir et vous montre le taux avant que vous acceptiez. Chaque montant converti s'affiche à côté de l'original, pour que vous voyiez toujours ce que la boutique facture vraiment.

POURQUOI IL DEMANDE À LIRE ET MODIFIER LES DONNÉES DE TOUS LES SITES
Un prix peut se trouver sur n'importe quelle boutique, donc Twinprice doit regarder les pages que vous ouvrez pour le repérer. Il ne les lit que sur votre appareil. Le contenu des pages, les prix et les sites visités ne quittent jamais votre navigateur. La seule chose envoyée est un code de devise à trois lettres, comme EUR, pour obtenir le taux de référence du jour. Pas de publicité, pas d'analyse, pas de pistage. Le code est libre (licence MIT) : github.com/somewordshere/twinprice

CE QUE VOUS POUVEZ CONVERTIR
- Tous les prix d'une page, en un clic
- Un seul prix que vous sélectionnez
- N'importe quel montant saisi dans la fenêtre de l'extension

DEVISES
- Plus de 160 devises de destination, avec recherche par code ou par nom
- 50 devises détectées automatiquement sur la page
- Formats corrects, comme le yen sans décimales et le dinar avec trois

PENSÉ POUR DE VRAIES BOUTIQUES
- Gère les affichages de prix compliqués, par exemple sur Allegro, Digitec, Trendyol et tap.az
- Repère les prix qui se chargent plus tard
- Marquez vos boutiques habituelles pour que les prix s'y convertissent tout seuls
- Un clic remet la page exactement dans son état d'origine
- Raccourci clavier : Ctrl+Maj+Y (Commande+Maj+Y sur Mac)

À PROPOS DES TAUX
Les taux de référence viennent de Frankfurter, qui publie les taux de la Banque centrale européenne chaque jour ouvré. Ils servent à comparer des prix. Ce ne sont pas les taux qu'appliquera votre banque ou votre carte, et ils n'incluent pas les frais.

LIMITES
Les prix dans des images et dans certains cadres intégrés ne peuvent pas être convertis. Sur des pages inhabituelles, il faudra parfois choisir vous-même la devise d'origine.

Gratuit, sans compte. Disponible pour Chrome et Firefox, y compris Firefox pour Android.

Si Twinprice vous est utile, un court avis aide d'autres acheteurs à le trouver.
