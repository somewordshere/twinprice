# Korean listing (ko)

Chrome: Developer Dashboard > Store listing > language "Korean" > Description.
Firefox: Developer Hub > Edit Product Page > language "한국어".

---

해외 가격이 내 통화로 얼마인지, 페이지에서 가격이 있는 바로 그 자리에서 원래 가격 옆에 보여 줍니다.

다른 통화를 쓰는 쇼핑몰을 열면 Twinprice가 가격을 찾아 환산을 제안하고, 수락하기 전에 환율을 보여 줍니다. 환산된 금액은 원래 가격 옆에 나타나므로 쇼핑몰이 실제로 청구하는 금액도 항상 확인할 수 있습니다.

모든 웹사이트의 데이터를 읽고 변경하는 권한이 필요한 이유
가격은 어느 쇼핑몰에나 있을 수 있으므로, Twinprice는 가격을 알아채기 위해 사용자가 연 페이지를 살펴봐야 합니다. 페이지는 사용자의 기기에서만 읽습니다. 페이지 내용, 가격, 방문한 사이트는 브라우저 밖으로 나가지 않습니다. 외부로 보내는 것은 그날의 기준 환율을 가져오기 위한 EUR 같은 세 글자 통화 코드뿐입니다. 광고, 분석, 추적이 없습니다. 코드는 MIT 라이선스의 오픈 소스입니다: github.com/somewordshere/twinprice

환산할 수 있는 것
- 페이지의 모든 가격을 클릭 한 번으로
- 선택한 가격 하나
- 팝업에 입력한 원하는 금액

통화
- 코드나 이름으로 검색할 수 있는 160개 이상의 환산 대상 통화
- 페이지에서 자동으로 감지하는 50개 통화
- 소수점이 없는 엔화, 소수점 이하 세 자리인 디나르 등 올바른 형식

실제 쇼핑몰을 위한 설계
- 까다로운 가격 표시도 처리하며, Allegro, Digitec, Trendyol, tap.az 같은 쇼핑몰을 위한 수정 포함
- 최신 쇼핑몰 페이지에서 나중에 불러오는 가격도 감지
- 자주 쓰는 쇼핑몰을 지정하면 자동으로 환산
- 실행 취소를 누르면 페이지가 원래 상태 그대로 돌아갑니다
- 단축키: Ctrl+Shift+Y(Mac에서는 Command+Shift+Y)

환율 안내
기준 환율은 유럽중앙은행 환율을 영업일마다 공개하는 Frankfurter에서 가져옵니다. 가격 비교용이며, 은행이나 카드사가 실제로 적용하는 환율이 아니고 수수료도 포함되지 않습니다.

제한 사항
이미지 안의 가격과 일부 삽입된 프레임 안의 가격은 환산할 수 없습니다. 특이한 레이아웃에서는 원래 통화를 직접 선택해야 할 수 있습니다.

무료이며 계정이 필요 없습니다. Chrome과 Firefox(Android용 Firefox 포함)에서 사용할 수 있습니다.

Twinprice가 도움이 되었다면 짧은 리뷰를 남겨 주세요. 다른 쇼핑객이 Twinprice를 찾는 데 도움이 됩니다.
