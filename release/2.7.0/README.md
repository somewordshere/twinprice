# Release version 2.7.0

Release prepared 2026-11-23.

- Choose **Español (Latinoamérica)** under **Language** in Page options for the popup, welcome page, and on-page controls. Automatic language selection recognizes Latin American Spanish browser settings.
- The website and help guides are available at [twinprice.com/es-419/](https://twinprice.com/es-419/).

The Latin American Spanish localization has yet to be reviewed by a native speaker.

### Validation

All 154 unit tests, 84 Chromium browser tests, and 6 Firefox runtime tests passed. Firefox package validation reported zero errors, warnings, and notices. All nine localized pages were verified on the production website.
